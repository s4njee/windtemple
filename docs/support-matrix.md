# Support matrix: what this family adds

Story 1.6. This is a delta on Fire Temple's [support matrix](../../firetemple/docs/support-matrix.md), which covers WebGPU itself, the browsers that ship it, `rgba16float` targets, timestamp queries and the HDR canvas. It is also a delta on Earth Temple's [delta](../../earthtemple/docs/support-matrix.md), which covers indirect draws from compute, vertex pulling and multisampled `rgba16float`. This page covers only what Wind Temple leans on beyond those.

**Checked so far:** headless Chrome 156 on an Apple M1 Max (Metal 3), probed on 2026-10-30 from the dev server by `node experiments/support-probe.mjs` ([support-probe.json](studies/support-probe.json)), and Dawn under Node for the tests and studies. Safari, Firefox, Windows, Android and an integrated GPU are not checked yet; they belong to the device matrix (story 11.2). Spec facts below are from the WebGPU and WGSL specifications, not measured.

| What                                                        | Needed by                                                              | Spec                                                                                    | Chrome 156, M1 Max                                                                                                           |
| ----------------------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `maxComputeWorkgroupStorageSize`                            | 2.2: the cloth's positions in shared memory, 16 B a particle           | 16,384 bytes by default                                                                 | 32,768 offered. The solver asks for the default only, so a cloth is at most 1,024 particles                                  |
| `maxComputeInvocationsPerWorkgroup`                         | 2.2: one workgroup of 256 solves the cloth                             | 256 by default                                                                          | 1,024 offered; 256 used                                                                                                      |
| A full 16 KiB `var<workgroup>` array                        | 2.2                                                                    | Core                                                                                    | Works: 1,024 `vec4f` filled and summed exactly                                                                               |
| What a dispatch costs                                       | 2.2: one dispatch a frame, or one per constraint colour                | —                                                                                       | 4.5 to 4.9 µs a trivial dispatch in one compute pass: 240 of them (15 phases × 16 substeps) are 1.1 ms of overhead           |
| `dispatchWorkgroupsIndirect` from counts written in compute | 5.2, 7.1: confetti and flocks whose counts change                      | Core. A buffer written as storage cannot be read as indirect arguments in the same pass | Works, from a separate pass. Written and read in one pass, or bound as storage in the reading pass, it is a validation error |
| `u32` storage atomics as fixed point                        | 6.1 and later: forces scattered onto grids (WGSL has no float atomics) | Core                                                                                    | Exact: 4,096 additions of 0.001 in units of 1/65,536 sum to the expected count                                               |
| `float32-filterable`                                        | 6.1: air velocity textures sampled with filtering                      | Optional feature                                                                        | Offered                                                                                                                      |
| `subgroups`                                                 | 7.1: flock neighbour reductions                                        | Optional feature                                                                        | Offered. Not relied on yet                                                                                                   |
| `shader-f16`                                                | Not used                                                               | Optional feature                                                                        | Offered. Half-float writes truncate on Apple GPUs (Fire Temple 5.6), so simulation state stays `f32`                         |
| Timestamps written by a compute pass                        | 2.8: timing the cloth's substeps                                       | `timestamp-query`                                                                       | Works                                                                                                                        |
